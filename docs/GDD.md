**三根支柱**

1. **對峙是主菜，不是開場動畫。** 一場決鬥會對峙三到五次，每一次對手都多一個花招。

## 1. 世界觀

**靜鐘鎮**（Stillbell）。沙漠裡的一個鎮，教堂塔上掛著一口鐘。

自從那口鐘掛上去，鎮上就沒有人死得了。被馬踢、被槍打、從屋頂摔下來，痛是真的，躺一陣子又會起來。

只有一個例外：**鐘響的時候，街上面對面站著的兩個人，輸的那個是真的死。** 所以鎮上的人把所有解決不了的事都留給鐘。

那口鐘第一次響，是七年前。它要一條命才肯響，鎮上挑了一個路過的外地人，安了個罪名，吊在教堂前面。

那個人是你。你在棺材裡醒過來，脖子上一圈繩印，花了七年才把土挖開。

當年有十個人各出了一份力：做棺材的、開賭盤的、作證的、驗屍的、警長、指認你的寡婦、牧師、劊子手、出錢買鐘的、判你的。沒有一個人覺得自己是兇手，因為每個人都只做了一小件事。

- **輸了不會死**：你不是在決鬥裡輸的那種死法——鐘不收你，因為你已經是它的了。你輸了，會在棺材裡再醒一次。這就是重試。
- **鎮民**：死不了的人很閒。每場決鬥整條街都是人，坐在屋頂、陽台、水槽上看。
- **基調**：乾、慢、有點好笑。沒有人覺得自己是壞人，他們只是當年都在場。

## 2. 主角

**多伊**。判決書上寫的名字是「約翰·多伊」——就是「無名氏」。沒有人問過你叫什麼，鎮上的人到現在還是這樣叫你。

第一人稱只看得到一雙手和偶爾垂進視野的一截斷繩——你一直沒把它從脖子上拿下來。話很少，聲音是啞的。

### 2.1 主角的能力：憋氣

被吊過的人，知道最後一口氣可以撐多久。

- **按住憋氣**：世界變慢、變安靜，準星穩住。有一條「氣」的量，約 3 秒，放開後慢慢回復。
- **看得見死線**：憋氣時，你看得到子彈會走的路——對手槍口延伸出來的一條線，還有子彈打到鐵器會彈去哪裡。
- **代價是聽不見**：憋氣時所有聲音都悶住，包括鐘聲、對手扳擊錘的聲音、他對你說的話。有些 Boss 你必須聽，有些 Boss 你最好不要聽。
- 氣用完會嗆到：準星大晃 1.5 秒。

這是唯一的能力，不能換。它同時是進攻工具（穩住準星、看彈跳路線）和防守工具（看見對手瞄哪裡）。

## 3. 戰鬥系統

### 3.1 一場決鬥的結構

```
入場 → 對峙 → 槍戰 → 有人掉一條命 → 回原位 → 對峙 → 槍戰 → …… → 最後一條命 → 最後一槍
```

- 你有 **3 條命**，Boss 有 **3–5 條命**。
- 每條命是一小段血。一條命打空，槍戰立刻停，雙方走回原位，鐘再響一次。
- Boss 每掉一條命就進下一階段：對峙多一個花招，槍戰多一兩招。
- 你的命在場與場之間補滿，同一場內不補。

### 3.2 對峙

雙方站在各自的位置，槍在槍套裡。鐘響之前誰都不能拔。

**流程**

1. **靜候**（3–8 秒，長度隨機）：你可以轉頭看、可以移動準星先對好位置，但不能拔槍。
2. **手**：按住【右鍵】把手懸在槍柄上。懸著，拔槍快；但懸越久手越抖，拔出來準星越散。什麼時候把手放上去，是第一個決定。
3. **鐘響**：按【左鍵】拔槍。槍舉起來時準星是一大圈，約 0.6 秒內收小。
4. **開槍**：再按一次【左鍵】。圈還大的時候開，快但可能打歪；等圈收小再開，準但可能來不及。

**搶拔**：鐘響之前按了拔槍，算犯規。鐘會罰你——槍柄燙手，這一次你拔不出來，只能挨這一槍。

**打到哪裡**

| 部位 | 結果 |
|---|---|
| 頭、心口 | 直接拿走對方一整條命，馬上進下一次對峙 |
| 軀幹 | 打掉這條命的六成，進槍戰 |
| 手臂 | 打掉三成；對方接下來 5 秒準頭變差 |
| 腿 | 打掉三成；對方接下來 5 秒走不快、不能翻滾 |
| 沒中 | 什麼都沒有，進槍戰，而且你槍裡少一發 |

對手打你也是同一張表。雙方都中，就兩邊都算。

**Boss 的拔槍時間**（鐘響到他開槍）：第一名 1.3 秒，逐關縮短到最後一名約 0.7 秒，同一名 Boss 每掉一條命再快一點。不低於人能反應的範圍。

### 3.3 槍戰

對峙沒有直接分出一條命，就進槍戰。可以跑、可以躲、可以翻滾，直到有人掉一條命為止。

**你能做的事**

| 動作 | 說明 |
|---|---|
| 開槍 | 腰射快而散；按住瞄準則準、走得慢。 |
| 裝彈 | 轉輪一次只能塞一顆。按一下裝一顆，按住就一顆接一顆；隨時可以停下來開槍。空槍在別人面前裝六顆，是這個遊戲最危險的六下。 |
| 翻滾 | 短暫無敵，穿得過子彈。有 2 次，用完要等。 |
| 蹲、躲 | 木箱、水槽、馬車擋得住子彈，但會被打爛。 |
| 憋氣 | 見 §2.1。 |
| 換槍 | 身上一把短槍、一把長槍，切換要時間。 |

**搶拍**——取代舊版的彈反

對手開槍之前一定先扳擊錘：有一聲「喀」、槍口有一點反光。**從他扳擊錘到開槍之間打中他，叫搶拍**：他那一槍作廢，而且膽大減。

打得準不夠，要打在對的時間。這是技術的核心。

**膽**——取代舊版的架勢

雙方各有一條膽。

- 子彈擦過身邊、被搶拍、身邊的掩體被打爛、挨槍，膽會掉。
- 打中人、搶拍成功、站在空地不躲，膽會漲。
- **膽見底就是「慌」**：約 3 秒內手抖、裝彈會掉子彈、不會還手。對手慌的時候是你大量輸出的時間；你慌的時候最好在掩體後面。
- 對 Boss 來說，慌就是破綻。壓制他 → 他慌 → 把子彈打進去。

所以槍戰的節奏是：**逼他開槍 → 搶拍或躲掉 → 壓到他慌 → 兌現**。一直躲著打不贏，因為躲著自己的膽也在掉。

**跳彈**

鐵器（鐘、鐵砧、招牌、馬蹄鐵門）會彈子彈。憋氣時看得到彈跳路線。有些 Boss 躲的地方只有跳彈打得到。

**最後一槍**

Boss 最後一條命打空時不會立刻倒：他跪著，或靠著牆，把話講完。你舉槍，開最後一槍。這一槍有子彈視角的慢鏡頭。（這不是處決系統，沒有操作成分，就是一槍。）

## 4. 槍

沒有改裝。槍就是槍，每一把打法不同。身上帶一把短槍（對峙只能用短槍）和一把長槍。用賞金在鎮上的槍鋪買。

**短槍**

| 名稱 | 取得 | 特性 |
|---|---|---|
| 老單動 | 起始 | 六發。每一槍要先扳擊錘，所以射速有上限，但最準。 |
| 雙動 | 一場後可買 | 六發。扣到底就打，快，但準星收得慢。對峙吃虧，槍戰佔便宜。 |
| 大口徑 | 三場後可買 | 五發。一槍抵一槍半，後座大，拔槍慢 0.08 秒。 |
| 掌心雷 | 二場後可買 | 兩發。拔槍最快，五步外打不準。對峙專用的賭博。 |

**長槍**

| 名稱 | 取得 | 特性 |
|---|---|---|
| 槓桿步槍 | 起始沒有長槍；一場後送 | 八發。準、遠，每槍要拉槓桿。 |
| 雙管霰彈 | 二場後可買 | 兩發。近距離打爛掩體和膽，十步外沒用。 |
| 單發重步槍 | 四場後可買 | 一發。打穿木頭掩體，裝彈很久。 |

共 7 把。要不要讓 Boss 掉「怪槍」（帶超自然效果），見 §12 的問題。

| 槍 | 一把左輪，九顆子彈，每一顆刻著前面一個人的名字 |
| 怪處 | **本庭規定。** 他的法槌就是那口鐘的鐘舌。他敲一下、說一條規定，那條規定就寫在天上，而且是真的：「本庭規定，不得翻滾。」「本庭規定，子彈往回飛。」「本庭規定，地在上面。」（整個場地翻過來，你們站在天花板上打。）「本庭規定，被告只有一發。」雙方都要守——但規定是他定的，而且他可以撤銷。**傳喚證人。** 他每開一槍，子彈上刻著誰的名字，誰的本事就出來一次：棺材、牌、歪掉的人影、布偶、鐵欄、死人的手、色光、繩子、停錶。 |

### 結局

法官也是你開的最後一槍。然後你站在鐘下面，手上是法槌。沒有選項框，看你做什麼：

- **敲鐘**：鎮上的人繼續死不了。你坐進法官的位置。下一個路過的人進了鎮。
- **把槌子丟下塔**：鐘再也不會響。欠了七年的，鎮上一夜之間還清。你也是其中一個。
- **拿著槌子走出鎮**：鐘舌不在鎮上了。你走到鎮界的木樁前面。走不走得過去，畫面停在你抬腳的時候。

之後開放二周目（每個人多一個花招、拔槍再快一點）。

### 文本規範（沿用並調整）

1. 每個人只用自己那一行的話。棺材匠講尺寸和木頭，警長講規矩，劊子手講服務。
2. 沒有人解釋自己的怪處。
3. 沒有人說「命運」「正義」「復仇」。沒有金句、沒有排比。
4. 沒有人承認自己是壞人，也沒有人喊冤。他們講的是當天的一件小事。
5. 輸了的台詞會記次數。
6. 主角全程不超過十句話。牧師那一場，他有機會說，他不說。

## 7. 演出

- **對峙本身就是演出**：風聲、招牌吱呀響、鎮民安靜下來。你的手在畫面下緣，對手在街的另一頭很小。鐘繩在塔上。
- **入場**：每個人做一件只有他會做的事——克雷恩拿皮尺隔空量你；馬洛把一枚硬幣彈到你腳邊；范恩走上證人席，人影坐下了，影子還站著；奎爾醫生把你的牙放在桌上；警長把鑰匙圈甩在地上，鐵欄從你腳邊長出來；寡婦的六隻手替她掀開黑紗；牧師請會眾起立；劊子手幫你套繩圈；范德黑爾讓整條街停下來等他把話說完；法官讓你自己走上塔。
- **命中**：第一人稱。挨槍時畫面被打歪、濺血、耳鳴。打中對手時他整個人被打退半步，帽子飛掉、血噴在後面的牆上。
- **搶拍成功**：短暫慢動作，他的槍被打偏，一聲金屬響。
- **最後一槍**：子彈視角慢鏡頭，從你的槍口到他身上。
- **輸了**：畫面一黑。棺材蓋從裡面被推開，你坐起來，在棺材鋪裡。哈洛大媽的聲音從外面傳進來。
- **每掉一條命**：鐘響，雙方收槍走回原位。Boss 邊走邊講一句話。
- **能力發動**：每個 Boss 的怪處第一次出現時有一個專屬的短鏡頭（一秒內），之後不再打斷。

## 8. 難度

目標不變：每個 Boss 3–5 次過。

| # | 對手 | 預期嘗試 | 新的壓力 | 這時你該會的 |
|---|---|---|---|---|
| 1 | 克雷恩 | 2–3 | 無。把流程走一遍 | 對峙、裝彈、搶拍 |
| 2 | 馬洛 | 3–4 | 要打空中的小目標 | 瞄準、憋氣 |
| 3 | 范恩 | 3–4 | 看到的位置是假的 | 看影子、用憋氣找死線 |
| 4 | 奎爾 | 3–5 | 掩體沒用、要排優先順序 | 先打什麼 |
| 5 | 霍利斯 | 3–5 | 被關小、從縫裡打、單手 | 精準射擊、搶拍 |
| 6 | 克勞 | 3–5 | 四面八方 | 聽聲辨位 |
| 7 | 索恩 | 4–5 | 距離、地上的色光、聲浪 | 看地形、排優先順序、聽拍子 |
| 8 | 諾克斯 | 4–6 | 輸對峙直接少一條命、畫面顛倒 | 壓力下拔槍 |

讓人輸得明白的做法沿用舊版：每一槍前都有擊錘聲和反光、Boss 的招數少而固定、重試很快（棺材蓋一推就回到街上）。輸在同一招兩次，哈洛大媽會多講一句風涼話，裡面就是提示。

## 11. 製作順序

1. 對峙原型：一條街、一個稻草人對手、鐘、拔槍與準星。先確認這一段好玩。
2. 槍戰：裝彈、翻滾、掩體、搶拍、膽、憋氣。
3. 克雷恩完整一場。
4. 其餘九人、場地、結局。十個人的能力各不相同，這一步工作量最大。
5. 據點、教學、槍鋪、成長。
6. 平衡與打磨。
