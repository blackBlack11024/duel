**三根支柱**

1. **每一場都是一個人。** 沒有雜兵。每個對手有自己的武器、能力、說話方式，打三四次之後你會認識他。

3. **輸得明白。** 每次死亡都能說出死因。招式看得懂、聽得到，重試在五秒內開始。

## 1. 世界觀

大旱第四十年。鹽原上只剩一座水庫還有水，當地人叫它「乾壩」——因為從外面看，它早就乾了，水都在壩體裡面的舊蓄水廊道。

管水的人定了規矩：每季開一次賽，叫**落閘**。各聚落派一個人下到壩底，一對一打。壩上有六道閘，贏一場開一道，放出來的水歸贏家的聚落。打到第六道的人，可以見**閘主**。

下場的人叫**閘手**。閘手死在場上，聚落那一季就沒水。

- **壩底**：決鬥場。原本是洩洪道，兩側是四十公尺高的混凝土牆，觀眾坐在檢修走道上往下看。
- **工棚**：閘手住的地方，在壩腳。有工作檯、鍛爐、靶場。這是玩家的據點。
- **水票**：貨幣。一張換一瓢水。場邊的賭盤用它，工棚的零件也用它買。

基調：粗、乾、有點好笑。沒有人談理想，大家談的是水、零件、誰欠誰一頓飯。

## 2. 主角

**釘子**（綽號。本名在故事裡只出現一次）。三號井聚落的修械工。性別不指定，第一人稱下只看得到一雙手：指節有舊燙疤，左手無名指少一截。

- 上一季三號井派的是釘子的師傅，死在第三閘。這一季沒人肯去，釘子去了。
- 話少。看人先看對方手上的傢伙，再看人。
- 不是戰士。打架的方式是修東西的方式：找出哪個零件在出力，把它拆掉。

### 2.1 主角能力：卸件

修械工的本事。這是整個戰鬥系統的軸心，也是玩家「學會一個 Boss」的具體形式。

- 完美彈反、閃避反擊會累積**扳手計**（三格）。
- 滿三格後，在對手出招的特定瞬間按下能力鍵，釘子會伸手抓住對方的武器，**卸下一個零件**。
- 每名 Boss 有 2–3 個可卸零件，各自對應他最危險的一招或一個機制。卸掉後該招式失效或弱化 25 秒，零件掉在地上；Boss 會找機會撿回去裝上（可以打斷）。
- 第一次打，你不知道能卸什麼。第三次打，你知道該留著扳手計等哪一招。

卸下來的零件戰後會留在你手上——這是**藍圖**的來源（見 §5）。

### 2.2 主角的筆記本

釘子有一本油漬很重的筆記本，工棚裡可以翻。同一招死兩次，本子上會多一頁**草圖**——釘子不太寫字，用畫的：

- 老鮑舉刀過肩的火柴人，刀上打一個叉（別擋），腳邊一個箭頭往他左邊繞。
- 郵差往後滑的三連拍，最後一格旁邊畫一個圈（等這裡）。
- 姑婆的煙罐，罐身畫一道裂痕。

修械工畫圖的方式：像零件爆炸圖，有箭頭、有圈、有叉，偶爾一兩個字的批註。不是教學彈窗，是玩家自己「發現」的延伸。可在選項關閉。

## 3. 核心戰鬥

### 3.1 三條資源

| 資源 | 作用 |
|---|---|
| **血量** | 歸零即死。水壺回血，每場 3 口，喝水有 0.9 秒硬直。 |
| **體力** | 攻擊、閃避、格擋、衝刺都消耗。停手 0.6 秒後開始回復。見底時格擋必破。 |
| **架勢** | 被擊中、被彈反、格擋重擊時累積。滿了就**崩架**：2.5 秒無法動作，可被處決。隨時間回落，血量越低回落越慢。 |

Boss 用同一套規則。玩家和對手是對稱的——這也是雙人對戰能直接成立的原因。

### 3.2 兩種架勢，一鍵切換

玩家同時帶一把冷兵器、一把槍、一件奇械。用**架勢切換**（0.2 秒）在兩種姿態間換手：

| | 近戰架勢 | 射擊架勢 |
|---|---|---|
| 主攻擊 | 輕擊（點按）／重擊（長按蓄力） | 開槍 |
| 副動作 | 格擋／彈反 | 瞄準 |
| 防禦手段 | 格擋、彈反、閃避 | 只有閃避 |
| 定位 | 累積對手架勢、創造破綻 | 兌現破綻、打斷、遠距壓制 |

舉槍的時候你擋不了刀。這是整個遊戲的基本風險。

**換手連段**：近戰命中後 0.4 秒內切到射擊架勢，第一發出槍時間縮短 40%。反過來，開槍命中後切近戰，第一下輕擊前搖縮短。鼓勵兩邊來回，而不是選一邊打到底。

### 3.3 槍為什麼不會毀掉決鬥

- **護板規則**：對手未崩架時，槍傷只有 40% 打進血量，其餘 60% 轉為架勢傷害。崩架中的對手吃 150% 槍傷。所以槍永遠有用，但想靠槍直接打死人，得先把架勢打崩。
- **子彈是錢**：每場帶彈量固定且少（左輪 18 發、霰彈 8 發）。完美彈反回 1 發，處決回滿一輪。
- **偏斜**：持冷兵器時，在槍響前 0.15 秒內格擋可偏斜子彈。所有槍械開火前有瞄準線與擊錘聲，Boss 的槍也一樣。
- **裝填是破綻**：裝填中被擊中，架勢傷害 ×2。Boss 也是。

### 3.4 防禦

| 動作 | 數值（60fps 基準） | 說明 |
|---|---|---|
| 閃避 | 全長 0.55s，無敵 0.08–0.35s | 耗體力 22。可取消輕擊後搖。 |
| 格擋 | 即時 | 依武器的格擋穩定度扣體力；重擊會打進架勢。 |
| 彈反 | 格擋後前 0.15s | 成功：對手吃大量架勢傷害、+1 扳手計、慢動作 0.12s。失敗就是普通格擋，沒有額外懲罰。 |
| 不可擋招 | — | 紅光 + 低頻音。只能閃或卸件。 |

彈反失敗不罰，是為了讓玩家敢試。難度來自 Boss 的節奏變化，不是來自操作懲罰。

### 3.5 處決

對手崩架時靠近按互動鍵。Boss 有多條**閘條**（等於階段血條，前三名 2 條、後三名 3 條），一次處決扣掉當前整條並進入下一階段。不處決也能把血磨完，但慢得多。

處決是第一人稱演出，長度 2–3 秒，全程無敵，依**武器類別**有不同動作（見 §8）。

## 5. 改造系統

三張工作檯，對應三類武器。原則：

- **每個零件都是取捨**，沒有單純加數字的零件。
- **用現實的道理**。玩家就算沒摸過槍、沒打過鐵，看了說明也會覺得「喔，合理」。
- **零件會被卸。** 閘主（以及雙人對戰中帶「卸件」的對手）可以在場上把你的改裝件拆掉。你裝得越花，能被拆的就越多。

共用資源：**廢料**（每場都有，輸了也給一點）、**精件**（擊敗 Boss、完成挑戰）、**水票**。

技術逐步解鎖：打贏一個人，學到他那門手藝。

| 擊敗 | 解鎖手藝 | 開放內容 |
|---|---|---|
| 老鮑 | 磨刀 | 刃角、開刃方式、配重 |
| 薛快 | 車管 | 槍管加工、膛線、彈道、瞄具 |
| 阮金枝 | 配方 | 化學藥劑、蟲群品系、彈頭塗層 |
| 啞鈴 | 裝藥 | 手工復裝、引信、裝藥量 |
| 葛蘭 | 液壓 | 氣動／液壓件、重武器結構、熱處理爐溫控制 |
| （卸件所得） | 藍圖 | 各 Boss 武器上的專屬零件 |

### 5.1 改槍（工作檯）

| 部位 | 選項舉例 | 取捨 |
|---|---|---|
| 槍管 | 鋸短／原長／加長重管 | 短：出槍快、擴散大、初速低（遠距傷害衰減）。長：相反，且架勢切換變慢。 |
| 膛線 | 原廠／重拉快纏距／磨成滑膛 | 快纏距穩重彈頭、利遠距；滑膛可打散彈但精度崩。 |
| 扳機組 | 輕扳機／兩道火／原廠 | 輕：連射快，但受擊時可能走火浪費一發。 |
| 供彈 | 快拔輪夾／加長彈倉／側掛彈帶 | 容量 vs 裝填時間 vs 重量。 |
| 槍托握把 | 鋸托／折疊托／配重托 | 後座控制 vs 架勢切換速度。 |
| 槍口 | 制退器／消焰器／無 | 制退：後座小、槍口焰大（自己的畫面會白一下）。 |
| 瞄具 | 機械／缺口加寬／簡易光學 | 光學瞄得準，瞄準時周邊視野變窄。 |
| 彈藥（需「裝藥」） | 減裝／標準／強裝；軟鉛／鋼芯／岩鹽／獨頭 | 強裝：傷害與後座都高，**可靠度**下降。軟鉛打血、鋼芯打架勢、岩鹽幾乎不致命但打斷力強。 |

**可靠度**是槍的隱性成本：改得越極端，卡彈機率越高（上限 8%）。卡彈時要多按一次裝填鍵排除，0.5 秒。每場結束在工棚保養歸零。

數值面板：傷害、架勢傷害、有效距離、擴散、後座、出槍時間、裝填時間、可靠度、重量。全部以圖示 + 長條呈現，不寫數字（見 §12.3）。

### 5.2 鍛造（鍛爐）

| 步驟 | 選項 | 取捨 |
|---|---|---|
| 選料 | 彈簧鋼／鋼筋／鑄鐵／雜合廢料 | 硬度 vs 韌性。硬的利、容易崩口；韌的鈍、但格擋穩。 |
| 淬火 | 油淬／風冷／**水淬** | 水淬最硬最脆。在這個世界，水淬一把刀要花掉一張水票——是奢侈品，場邊的人會看得出來。 |
| 回火 | 低溫／中溫／高溫 | 低溫保硬度，高溫換韌性。決定耐久與崩口機率。 |
| 刃型 | 薄刃／凸磨／鑿形／不開刃 | 薄刃血傷高、耐久低。不開刃純打架勢。 |
| 配重 | 重心靠前／置中／靠柄 | 靠前：重擊強、收招慢。靠柄：揮速快、彈反窗口 +0.02s。 |
| 柄 | 短／長／纏布／加護手 | 距離、揮速、格擋穩定度。 |

鍛造有一段短操作：看火色下錘（三次時機判定）。判定好壞只影響 ±5% 品質，不做也能用預設值——想玩的人玩，不想玩的人不被卡住。

**刃口**：冷兵器在單場內會鈍，砍在格擋上鈍得更快。鈍了血傷降、架勢傷害不變。戰後自動修。

數值面板：血傷、架勢傷害、攻擊距離、揮速、收招、格擋穩定度、彈反窗口、耐久。

### 5.3 調校（調校台）

奇械不分零件，按**原理**調。

| 原理 | 適用 | 調校軸 |
|---|---|---|
| 機械彈力 | 回執、來回 | 弓臂磅數（力道 vs 上弦時間）、絞盤比（收線速度 vs 拉力） |
| 氣動 | 點名 | 氣瓶壓力（威力 vs 每瓶發數）、閥門口徑（射速 vs 單發力道） |
| 化學 | 睡吧 | 配方比例（濃度 vs 持續時間 vs 擴散範圍） |
| 生物 | 家當 | 品系（攻擊性 vs 續航 vs 追蹤距離）、餵食（數量 vs 冷卻） |
| 電 | 過電、借一下 | 電瓶容量（次數）vs 放電率（強度）、線圈圈數（距離 vs 耗電） |

## 6. 故事模式：六道閘

流程：工棚（改裝、靶場、翻筆記）→ 入場演出 → 決鬥 → 贏：開閘、取得武器與手藝／輸：回工棚，五秒內可重來。

場邊有一個固定角色貫穿全程：

**喇叭嫂**——賭盤莊家兼播報。嗓門大，市場叫賣的口氣，對誰都不客氣。她負責開場介紹和你每次死掉之後的那句話。

### 6.x 文本寫作規範

為了讓六個人聽起來是六個人，不是同一個寫手：

1. **每個人只用自己行當的詞。** 老鮑說斤兩，薛快說步數和地址，葛蘭說驗收。換個人說這句話會不成立，才算過關。
2. **沒有人解釋自己的能力。** 能力靠打過才懂，台詞不做說明書。
3. **沒有人說主題。** 不出現「命運」「宿命」「這就是生存」「有趣」「讓我看看你的能耐」「你很特別」。
4. **不對稱。** 不寫排比、不寫三段式、不寫金句。人講話會講一半、會岔題。
5. **死亡台詞會記次數。** 第一次和第四次聽到的不一樣，重試不會煩。
6. **敗北台詞交代一件實際的事**（梯子鬆了、蜂箱要蓋、鑰匙在口袋）。人輸了以後想的是手邊的事。
7. **釘子全程不超過十句話。**

## 8. 演出

第一人稱的原則：**鏡頭永遠是你的頭**。不切第三人稱，不拿走控制權超過 6 秒，所有演出首次之後可跳過。

### 8.1 入場

每個 Boss 的入場都會對「你」做一件事，而不是自己擺姿勢：

- **老鮑**：一隻手抓住你的領子把你提離地面，掂兩下，放下來。標題卡在你落地時砸出來。
- **薛快**：你走進廊道，一張標籤「啪」貼在你胸口。你低頭看，抬頭時他已經倒吊在梁上。
- **阮金枝**：她背對你在餵蟲。你走近，一隻蟲停在你的槍管上。她說「來，站近一點」。
- **啞鈴**：你踩到一個東西，喀一聲。他在場的另一頭舉起紙板：「你好」。
- **葛蘭**：四面鋼板在你身後升起來。她看錶。
- **閘主**：沒有入場。他坐在閘輪旁邊，遞水壺給你。你喝，或不喝，然後他站起來。

標題卡格式統一：一行粗字閘號、一行名字、喇叭嫂報賠率的聲音壓在上面。

### 8.2 處決

依你手上的**武器類別**決定動作，每個 Boss 的最後一條閘條有專屬收尾。

| 類別 | 動作概念 |
|---|---|
| 鈍器（老伴、收工） | 左手抓對方領口拉近，右手由下往上。 |
| 刃器（半扇、割蜜） | 撥開對方武器，一刀，轉身，甩血。 |
| 長柄（三分筋、半圓） | 掃腿放倒，柄尾砸下。 |
| 短槍（六孔、對半） | 槍托砸臉，退半步，腰射。 |
| 長槍（掛號、長嘴、點名） | 槍管架在對方肩上開。 |
| 奇械 | 各自專屬（回執：鉤住拉過來接膝撞；過電：叉進護板縫再通電）。 |

Boss 處決你也有演出（2 秒，可跳）。被老鮑打死是被放上磅秤。

### 8.3 階段轉換

每條閘條打掉時，壩上對應的一道閘會漏一點水下來——到第六閘，你打的時候頭上在下雨。

## 9. 難度與成長

目標：**每個 Boss 3–5 次過**。第一次看招，第二次試打法，第三次開始能贏。

### 9.1 讓人輸得明白

- **招式池小**：每階段 4–6 招。新階段加 2 招，不整套換。
- **前搖有下限**：第一閘最快 0.45 秒，逐關縮到終局 0.30 秒。沒有低於人類反應的招。
- **每招三重提示**：動作輪廓、聲音、（不可擋招）紅光。
- **節奏騙招從第三閘才出現**（延遲出手、假動作）。前兩關讓玩家建立信任。
- **重試五秒**：死亡 → 喇叭嫂一句話 → 站在場上。入場演出第二次起自動跳過。
- **筆記本**（§2.2）：同一招死兩次，多一頁草圖。

### 9.2 難度曲線

| 閘 | 預期嘗試 | 預期單場時間 | 新增壓力 | 玩家此時該會的 |
|---|---|---|---|---|
| 1 老鮑 | 2–3 | 2–3 分 | 體力懲罰 | 格擋、彈反 |
| 2 薛快 | 3–4 | 3 分 | 遠距、機動 | 偏斜、追擊時機 |
| 3 阮金枝 | 3–5 | 3–4 分 | 場地、延遲出手 | 目標優先序 |
| 4 啞鈴 | 4–5 | 4 分 | 位置、三階段 | 走位、利用環境 |
| 5 葛蘭 | 4–6 | 4–5 分 | 霸體、空間壓縮 | 卸件的時機選擇 |
| 6 閘主 | 5–7 | 5 分 | 鏡像、你的改裝被拆 | 全部 |

第三閘是故意的小高峰（劇情重量也在這），第四閘前給一次較大的裝備躍升（裝藥手藝）作緩衝。

### 9.3 數值成長

玩家的進步一半來自手、一半來自工棚。只靠裝備過不了，只靠技術會很辛苦。

| | 起始 | 終局（合理改裝） | 來源 |
|---|---|---|---|
| 血量 | 100 | 140 | 每兩閘 +20（護板升級） |
| 水壺 | 3 口 × 35 | 4 口 × 45 | 三閘後 +1 口，五閘後回復量提高 |
| 體力 | 100 | 120 | 四閘後 |
| 輸出 | 100% | 約 150% | 改裝 |
| Boss 血量 | 100% | 約 260% | — |
| Boss 單擊傷害（輕／重） | 18／32 | 26／48 | — |

→ 玩家始終能挨 3–5 下。每一閘 Boss 的成長略快於玩家的數值成長，差額由玩家的熟練度補。

**輸了也有進度**：每次嘗試給少量廢料（單一 Boss 累計有上限，防止刷）。卡關的人回工棚總有一件事可做。

### 9.4 輔助選項（不分難度等級）

彈反窗口 +0.05s、筆記本提示提早、關閉卡彈、Boss 處決演出關閉。開了不扣成就，不提示。

## 10. 雙人對戰（暫緩）

> 目前決定先不做。以下設計保留。程式裡已有直連版本（`src/net.gd`、`src/fight.gd` 的對戰部分、工棚的大廳），由 `src/game.gd` 的 `ONLINE` 開關控制，預設關閉。

**線上一對一**。只做朋友對戰：一方開房拿到房間碼，另一方輸入加入。第一版不做隨機配對、不做排名。

| 項目 | 規格 |
|---|---|
| 連線 | 一方當主機，另一方連入。透過中繼服務打洞／轉送，玩家不需要設定路由器。（中繼方案待定，見 §15） |
| 賽制 | 三戰兩勝。每回合血 100、水壺 1 口、90 秒，時間到比血量百分比。 |
| 場地 | 故事模式的六個場地（無 Boss 機關版）+ 可選機關版。 |
| 處決 | 崩架後可處決，短版 1.5 秒，直接結束該回合。 |
| 溝通 | 沒有文字聊天。六個手勢／表情動作（點頭、指地板、攤手、敲武器……），第一人稱看得到對方做。 |
| 再戰 | 打完雙方各按一次即重開，不回大廳。 |

### 10.1 配置：十點預算

雙方各有 10 點，自由組合一把冷兵器、一把槍、一件奇械、一個核心。

- 武器 1–3 點（例：六孔 1、對半 2、長嘴 3）
- 核心 1–3 點（例：過磅 1、卸件 2、工期 3）
- 每個改裝件 0–1 點
- 剩餘點數轉為額外水壺或彈藥

想帶最貴的槍，就帶不了最貴的核心。帶一身改裝，對面帶卸件就很痛。

配置畫面是工棚的桌面：武器擺在桌上，點數是桌角的一排水票，拿一件就少幾張。不用讀字。

### 10.2 模式

- **自選**：各自配置，互相看不到，進場才知道對方帶什麼。
- **輪選**：輪流選、輪流禁，像選牌。
- **抽籤**：隨機配置，隨機場地。最快開打。
- **原廠**：雙方同一套無改裝標準裝，純技術。

### 10.3 連線下的手感

這個遊戲的彈反窗口只有 0.15 秒，延遲處理不好就沒辦法玩。原則：

- **自己的動作立刻反應**。移動、揮刀、開槍、閃避都在本機先演，不等對方確認。
- **防守方說了算**。一刀有沒有被擋、被彈反、被閃掉，以「挨打那一方的畫面」為準。你看到刀來了、你按了擋，就是擋到了。代價由攻擊方承擔：偶爾看起來砍中了，零點幾秒後才知道被彈掉。讀招的遊戲裡，這比反過來好得多。
- **槍反過來，開槍方說了算**（在合理延遲範圍內回溯對手位置）。準星在人身上扣下去就是中。偏斜子彈仍由防守方判定。
- **對手的動作做緩衝播放**，並依延遲把對手招式的前搖在視覺上略為壓縮，讓判定時間點雙方一致。
- **延遲上限**：超過 150ms 時顯示一個紅色訊號圖示；超過 250ms 持續三秒，暫停回合等待恢復。
- **斷線**：該回合作廢，20 秒內可重連續打；逾時判離場。

### 10.4 平衡原則

- PvP 用獨立數值表，不受故事模式平衡牽連。
- 所有控場效果（癱瘓、拉人、遮蔽）單次上限 1 秒，同類效果有遞減。
- 各看各的螢幕，所以隱蔽是真的：煙會擋視線，絆雷只有佈雷者看得清楚（對手只在近距離看得到反光）。相應地，每種隱蔽手段都有聲音可以聽。
- 故事模式的進度不鎖對戰內容。對戰模式一開始全武器、全核心、全零件開放。
- 只做朋友對戰，不做反作弊。主機的結算為準。

## 12. 介面與教學：少字

規則：**角色講的話可以是字，其他盡量不是。** 玩家不該需要讀任何東西才知道怎麼玩。選項選單、字幕、角色台詞、標題卡是例外。

### 12.1 戰鬥畫面

沒有傳統血條排在畫面角落。資訊長在你看得到的東西上：

| 資訊 | 怎麼呈現 |
|---|---|
| 自己的血量 | 左前臂上綁的一排護板，受傷一片片裂開、掉落。瀕死時畫面邊緣變暗、心跳聲。 |
| 體力 | 呼吸聲和武器的晃動幅度。見底時手明顯在抖。準星下方只有一條細弧線，滿的時候隱藏。 |
| 自己的架勢 | 準星外圈收緊、變紅。快崩時鏡頭有輕微失衡。 |
| 水壺 | 掛在腰側，低頭或喝水時看得到剩幾格刻度。 |
| 彈藥 | 看槍本身：左輪彈巢露在外面、霰彈槍側掛彈帶、氣瓶有壓力錶。不顯示數字。 |
| 扳手計 | 右手腕上三顆螺帽，累積一格亮一顆，滿了會輕震並發出棘輪聲。 |
| 對手的血／閘條 | 對手胸口的護板（幾條閘條就是幾塊大護板），裂得越多越接近崩。 |
| 對手的架勢 | 對手的站姿：越來越晃、武器越舉越低、喘。崩架時護板彈開。 |
| 可卸件的時機 | 對手武器上那個零件閃一下金屬反光，並有一聲短促的「叮」。 |
| 不可擋招 | 紅光 + 低頻音（同 §3.4）。 |
| 被貼標、中毒、出血等狀態 | 直接出現在你手上：手背貼著標籤、手上爬著蟲、袖口在滴血。 |

準星是畫面上唯一固定的 UI 元素。

### 12.2 怎麼教

不出現「按 X 格擋」的文字框。四個手段：

1. **按鍵圖示貼在世界裡。** 第一次需要某個動作時，那顆鍵的圖示（鍵帽或手把按鈕的形狀）出現在相關物件旁邊：老鮑的刀舉起來時，圖示浮在他的刀上；可處決時浮在對手身上。做對三次後永久消失。
2. **工棚裡的木樁是教學關。** 開場不直接進第一閘。工棚有一具會動的訓練樁（釘子自己焊的，會揮一根鐵管）。它只會三個動作：慢揮、快揮、開一槍。玩家在這裡摸到格擋、彈反、偏斜。沒有通過條件，想走就走。
3. **第一閘本身是教學。** 老鮑前三十秒只出一招，而且很慢。他的台詞順便教（「別躲，躲了我要多走兩步」——所以該躲）。
4. **做對了有明確回饋，做錯了看得出差在哪。** 彈反太早或太晚，火花的顏色不同（早是暗紅、晚是白、剛好是金）。不寫「太早」。

死亡後不出現提示文字。喇叭嫂講一句、筆記本可能多一頁圖，就這樣。

### 12.3 工棚與改造介面

- **沒有選單清單。** 工棚是一個可以走動的房間：工作檯、鍛爐、調校台、靶場、筆記本、通往壩底的門。走過去就是進入那個功能。
- **改槍是直接動手。** 槍以爆炸圖的方式攤在檯面上，可換的部位會微微浮起。抓起一個零件，檯面上會擺出可以換上去的其他零件（實物模型，不是文字列表）。
- **數值用圖示 + 長條**，每項一個圖示（靶心＝精度、彈殼＝裝填、彈簧＝後座……）。換零件時，長條上直接顯示變長變短的那一段：綠色是變好、紅色是變差。沒有數字、沒有百分比。
- **取捨看得見。** 每個零件一定同時有綠有紅，一眼知道代價。
- **零件名稱只在拿起來時出現**，一個詞（「鋸短」「水淬」「輕扳機」），是整個改造介面裡唯一的字。
- **試了才知道。** 工作檯轉身就是靶場，換完零件三秒內能打到靶。靶場有一具會格擋、會後退的假人，量給你看的不是數字，是「幾下打崩它」。
- **鍛造**全程是動作：把料夾進爐、看火色、拉出來、下錘、插進淬火桶。火色和聲音就是提示。
- **資源**：廢料是檯邊的一箱鐵件，精件是牆上掛的幾個零件，水票是桌角的一疊紙。夠不夠用，看那個零件模型是實心還是虛影。
- **手藝解鎖**：打贏誰，工棚牆上就多一件他的東西（老鮑的磨刀石、薛快的車床刀具……），對應的檯面多出一格可動的部位。

### 12.4 主選單與其他

- 主選單是站在壩腳的第一人稱畫面：往工棚走是繼續故事，往另一扇門走是對戰，牆上的收音機是選項。
- 對戰大廳：房間碼用六個圖形符號（齒輪、水滴、扳手……），不是英數字，唸給朋友聽也不會錯。
- 選項選單是唯一的傳統文字介面，這個沒必要為了少字犧牲清楚。
- 所有圖示提示都可在選項切換成「圖示 + 文字」，給需要的人。

### 12.5 風險

少字的代價是有些規則玩家可能很久都沒發現（例如換手連段、護板規則）。對策：

- 這類進階規則放進筆記本的草圖，在玩家「差一點用上」的時候解鎖該頁（例如近戰命中後一秒內切槍開火，累計五次就給換手連段那頁）。
- M1 試玩時專門觀察：不給任何口頭說明，看新玩家多久發現彈反、卸件、處決。發現不了的就是介面要改的地方。

## 13. 技術架構（Godot 4）

```
res://
├── core/           # Combatant（戰鬥者）、狀態機、資源條、傷害結算
├── input/          # InputSource 抽象：LocalInput / AIInput(行為樹) / RemoteInput(網路)
├── weapons/        # WeaponDef、PartDef（Resource）；槍、冷兵器、奇械各一個基底場景
├── mods/           # 改造規則、數值合成、三張工作檯的 UI
├── bosses/         # 每個 Boss：招式表（Resource）、行為樹、可卸零件、台詞表
├── cores/          # 核心能力
├── arenas/         # 場地與機關
├── cinematics/     # 入場、處決、階段轉換（AnimationPlayer + 第一人稱相機軌）
├── story/          # 流程、存檔、筆記本、解鎖
├── versus/         # 配置預算、賽制、大廳
├── net/            # 連線、同步、延遲補償、判定仲裁
├── ui/
└── data/           # 所有數值表（.tres / .csv），PvE 與 PvP 分開
```

關鍵決定：

- **玩家與 Boss 共用同一個 `Combatant`**。差別只在輸入來源：本機、AI、或網路另一端。這保證 Boss 遵守跟玩家一樣的規則，也讓對戰不必另寫一套戰鬥。
- **戰鬥邏輯從 M0 起就寫成「輸入進、狀態出」的確定性步進**，不依賴動畫回呼或物理引擎的隨機結果。連線是後面才做，但這個前提要一開始就守住，事後補救代價很高。
- **連線**用 Godot 內建的高階多人 API，一方為主機。命中判定依 §10.3 的規則仲裁。開發期先用區網直連，中繼方案定案後再接上。
- **武器 = 基底 + 零件清單**，數值在執行時合成。卸件就是從清單暫時移除一項。
- **招式是資料**：前搖、判定、後搖、可否格擋、架勢傷害、提示音，全部寫在 Resource。調平衡不改程式。
- **台詞表帶條件**（第幾次嘗試、當前階段、玩家帶什麼武器），不寫死在腳本。
- **測試**：戰鬥結算與數值合成寫成純邏輯，可用無頭模式跑自動測試；AI 對 AI 的模擬對戰用來粗抓平衡。

## 16. 實作與企劃的差異

做出來的版本和上面的企劃有幾處不同：

- **饒或殺**：最後一條閘條打完，Boss 會跪下把話講完。這時可以處決，也可以走到場地另一頭轉閘輪直接過關。企劃原本只有處決。
