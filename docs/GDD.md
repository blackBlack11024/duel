**三根支柱**

1. **對峙是主菜，不是開場動畫。** 一場決鬥會對峙三到五次，每一次對手都多一個花招。

## 1. 世界觀

**啞鐘鎮**。沙漠裡的一個鎮，教堂塔上掛著一口鐘。

自從那口鐘掛上去，鎮上就沒有人死得了。被馬踢、被槍打、從屋頂摔下來，痛是真的，躺一陣子又會起來。

只有一個例外：**鐘響的時候，街上面對面站著的兩個人，輸的那個是真的死。** 所以鎮上的人把所有解決不了的事都留給鐘。

那口鐘第一次響，是七年前。它要一條命才肯響，鎮上挑了一個路過的外地人，安了個罪名，吊在教堂前面。

那個人是你。你在棺材裡醒過來，脖子上一圈繩印，花了七年才把土挖開。

當年有六個人動了手：做棺材的、作證的、警長、牧師、劊子手、法官。六個人，六發子彈。

- **輸了不會死**：你不是在決鬥裡輸的那種死法——鐘不收你，因為你已經是它的了。你輸了，會在棺材裡再醒一次。這就是重試。
- **鎮民**：死不了的人很閒。每場決鬥整條街都是人，坐在屋頂、陽台、水槽上看。
- **基調**：乾、慢、有點好笑。沒有人覺得自己是壞人，他們只是當年都在場。

## 2. 主角

**吊過的**（鎮上的人這樣叫。沒有人記得你的名字，判決書上寫的是別人的）。

第一人稱只看得到一雙手和偶爾垂進視野的一截斷繩——你一直沒把它從脖子上拿下來。話很少，聲音是啞的。

### 2.1 主角的能力：憋氣

被吊過的人，知道最後一口氣可以撐多久。

- **按住憋氣**：世界變慢、變安靜，準星穩住。有一條「氣」的量，約 3 秒，放開後慢慢回復。
- **看得見死線**：憋氣時，你看得到子彈會走的路——對手槍口延伸出來的一條線，還有子彈打到鐵器會彈去哪裡。
- **代價是聽不見**：憋氣時所有聲音都悶住，包括鐘聲、對手扳擊錘的聲音、他對你說的話。有些 Boss 你必須聽，有些 Boss 你最好不要聽。
- 氣用完會嗆到：準星大晃 1.5 秒。

這是唯一的能力，不能換。它同時是進攻工具（穩住準星、看彈跳路線）和防守工具（看見對手瞄哪裡）。

## 3. 戰鬥系統

### 3.1 一場決鬥的結構

```
入場 → 對峙 → 槍戰 → 有人掉一條命 → 回原位 → 對峙 → 槍戰 → …… → 最後一條命 → 最後一槍
```

- 你有 **3 條命**，Boss 有 **3–5 條命**。
- 每條命是一小段血。一條命打空，槍戰立刻停，雙方走回原位，鐘再響一次。
- Boss 每掉一條命就進下一階段：對峙多一個花招，槍戰多一兩招。
- 你的命在場與場之間補滿，同一場內不補。

### 3.2 對峙

雙方站在各自的位置，槍在槍套裡。鐘響之前誰都不能拔。

**流程**

1. **靜候**（3–8 秒，長度隨機）：你可以轉頭看、可以移動準星先對好位置，但不能拔槍。
2. **手**：按住【右鍵】把手懸在槍柄上。懸著，拔槍快；但懸越久手越抖，拔出來準星越散。什麼時候把手放上去，是第一個決定。
3. **鐘響**：按【左鍵】拔槍。槍舉起來時準星是一大圈，約 0.6 秒內收小。
4. **開槍**：再按一次【左鍵】。圈還大的時候開，快但可能打歪；等圈收小再開，準但可能來不及。

**搶拔**：鐘響之前按了拔槍，算犯規。鐘會罰你——槍柄燙手，這一次你拔不出來，只能挨這一槍。

**打到哪裡**

| 部位 | 結果 |
|---|---|
| 頭、心口 | 直接拿走對方一整條命，馬上進下一次對峙 |
| 軀幹 | 打掉這條命的六成，進槍戰 |
| 手臂 | 打掉三成；對方接下來 5 秒準頭變差 |
| 腿 | 打掉三成；對方接下來 5 秒走不快、不能翻滾 |
| 沒中 | 什麼都沒有，進槍戰，而且你槍裡少一發 |

對手打你也是同一張表。雙方都中，就兩邊都算。

**Boss 的拔槍時間**（鐘響到他開槍）：第一名 1.3 秒，逐關縮短到最後一名約 0.7 秒，同一名 Boss 每掉一條命再快一點。不低於人能反應的範圍。

### 3.3 槍戰

對峙沒有直接分出一條命，就進槍戰。可以跑、可以躲、可以翻滾，直到有人掉一條命為止。

**你能做的事**

| 動作 | 說明 |
|---|---|
| 開槍 | 腰射快而散；按住瞄準則準、走得慢。 |
| 裝彈 | 轉輪一次只能塞一顆。按一下裝一顆，按住就一顆接一顆；隨時可以停下來開槍。空槍在別人面前裝六顆，是這個遊戲最危險的六下。 |
| 翻滾 | 短暫無敵，穿得過子彈。有 2 次，用完要等。 |
| 蹲、躲 | 木箱、水槽、馬車擋得住子彈，但會被打爛。 |
| 憋氣 | 見 §2.1。 |
| 換槍 | 身上一把短槍、一把長槍，切換要時間。 |

**搶拍**——取代舊版的彈反

對手開槍之前一定先扳擊錘：有一聲「喀」、槍口有一點反光。**從他扳擊錘到開槍之間打中他，叫搶拍**：他那一槍作廢，而且膽大減。

打得準不夠，要打在對的時間。這是技術的核心。

**膽**——取代舊版的架勢

雙方各有一條膽。

- 子彈擦過身邊、被搶拍、身邊的掩體被打爛、挨槍，膽會掉。
- 打中人、搶拍成功、站在空地不躲，膽會漲。
- **膽見底就是「慌」**：約 3 秒內手抖、裝彈會掉子彈、不會還手。對手慌的時候是你大量輸出的時間；你慌的時候最好在掩體後面。
- 對 Boss 來說，慌就是破綻。壓制他 → 他慌 → 把子彈打進去。

所以槍戰的節奏是：**逼他開槍 → 搶拍或躲掉 → 壓到他慌 → 兌現**。一直躲著打不贏，因為躲著自己的膽也在掉。

**跳彈**

鐵器（鐘、鐵砧、招牌、馬蹄鐵門）會彈子彈。憋氣時看得到彈跳路線。有些 Boss 躲的地方只有跳彈打得到。

**最後一槍**

Boss 最後一條命打空時不會立刻倒：他跪著，或靠著牆，把話講完。你舉槍，開最後一槍。這一槍有子彈視角的慢鏡頭。（這不是處決系統，沒有操作成分，就是一槍。）

## 4. 槍

沒有改裝。槍就是槍，每一把打法不同。身上帶一把短槍（對峙只能用短槍）和一把長槍。用賞金在鎮上的槍鋪買。

**短槍**

| 名稱 | 取得 | 特性 |
|---|---|---|
| 老單動 | 起始 | 六發。每一槍要先扳擊錘，所以射速有上限，但最準。 |
| 雙動 | 一場後可買 | 六發。扣到底就打，快，但準星收得慢。對峙吃虧，槍戰佔便宜。 |
| 大口徑 | 三場後可買 | 五發。一槍抵一槍半，後座大，拔槍慢 0.08 秒。 |
| 掌心雷 | 二場後可買 | 兩發。拔槍最快，五步外打不準。對峙專用的賭博。 |

**長槍**

| 名稱 | 取得 | 特性 |
|---|---|---|
| 槓桿步槍 | 起始沒有長槍；一場後送 | 八發。準、遠，每槍要拉槓桿。 |
| 雙管霰彈 | 二場後可買 | 兩發。近距離打爛掩體和膽，十步外沒用。 |
| 單發重步槍 | 四場後可買 | 一發。打穿木頭掩體，裝彈很久。 |

共 7 把。要不要讓 Boss 掉「怪槍」（帶超自然效果），見 §12 的問題。

## 5. 成長

沒有技能樹、沒有選擇題。**每贏一場，固定拿到一樣東西**，加上賞金。

| 打贏 | 得到 | 效果 |
|---|---|---|
| 棺材匠 | 他量你用的皮尺 | 對峙時準星收得快一成 |
| 證人 | 一副沒有聲音的耳塞（他的） | 憋氣時鐘聲不再被悶住 |
| 警長 | 他的彈帶 | 備彈多 12 發 |
| 牧師 | 一本挖空的聖經 | 氣多 1 秒 |
| 劊子手 | 你自己那條繩子的另一半 | 翻滾多 1 次 |
| 法官 | 判決書 | （結局用） |

數值成長很小。主要的成長是你自己：聽得出擊錘聲、抓得到搶拍。

## 6. 六個人

賭盤和開場白由一個固定角色負責：

**三姑**——酒館老闆娘，收賭注。嗓門大，講話像在趕蒼蠅。七年前她也在場，她是唯一一個沒有假裝不記得的人。

> 「下注下注！吊過的對棺材匠，一賠八。買吊過的？你錢太多是不是。」
>
> 「又躺了。抬回去抬回去，棺材鋪的門不用關，他等一下自己會走出來。」
>
> 「——贏了。賠八的來。……欸，七年了，總算有人領到這一筆。」

|---|---|
| 當年做了什麼 | 他知道抓錯人。他把你從牢裡帶出來，親手交出去，然後回去把牢門鎖好。 |

> **最後**　「我每天晚上都有鎖門。」
> 　　　　「七年，一天都沒忘。我以為這樣算是有在做事。」
> 　　　　「星星你拿去。它其實很重。」

### 第四發｜晚禱（牧師）

| | |
|---|---|
| 當年做了什麼 | 繩子套上去之前，他問你有沒有話要說。你還沒開口，他就說了阿們。 |
| 槍 | 槓桿步槍「晚禱」 |
| 怪處 | **應許**。會眾（就是看台上的鎮民）會跟著他唱。歌有拍子，他的子彈只在拍子上出來。他跪下來禱告時，傷會好。 |
| 對峙花招 | **他閉著眼睛**。他不看鐘，他聽歌：會眾唱到某一句，鐘才響。你要聽那首歌——所以這一場你不能憋氣撐過對峙。後面的階段會眾會唱錯拍。 |
| 槍戰 | 他在教堂另一頭，遠。步槍準。子彈跟著拍子來，聽得出拍子就躲得掉。長椅擋得住子彈但一排排會被打爛。他一跪下禱告就開始回血，要搶拍打斷——從正面打不到，他跪在講台後面，要用跳彈打鐘。 |
| 教什麼 | 聽。跳彈。和上一關相反：這次不能靠憋氣。 |
| 場地 | 教堂裡。長椅、講台、彩色玻璃，那口鐘就在正上方的塔裡。 |
| 命 | 4 |

**語氣**：溫和，像在對一屋子人講話，即使只有你。不直接回答問題。

> **開場**　「請坐。喔，你要站著。也好。」
> 　　　　「那天我問你有沒有話要說。」
> 　　　　「我後來想過，我好像沒有等你。」
>
> **槍戰中**　「第三節。大家一起。」
> 　　　　　「不要打椅子。那是奉獻買的。」
> 　　　　　「我為你禱告。」（然後開槍）
>
> **你輸了**　「阿們。」
> 　　　　　（第三次以後）「我們再唱一次。這次他會跟上的。」
>
> **最後**　「現在你可以說了。」
> 　　　　「那天你要說的話。我聽。」
> 　　　　（你沒有說話。）
> 　　　　「……也對。」

### 第五發｜活結（劊子手）

| | |
|---|---|
| 當年做了什麼 | 打的結。拉的桿。他做得很仔細。 |
| 槍 | 單發後膛步槍「落板」。一槍，然後要裝很久。 |
| 怪處 | **繩子聽他的**。絞架上垂下來的繩子會自己找人。他腳下的活板門他說開就開。 |
| 對峙花招 | **你站在活板門上，脖子上套著繩圈。** 鐘響，桿子也同時開始倒。你輸了這次拔槍，板子就開——直接少一條命。不能後退，不能蹲。後面的階段繩子會慢慢收緊，把你的視線往上拉。 |
| 槍戰 | 他只有一發，但那一發你擋不住也撐不住，只能滾開或搶拍。他裝彈很久，可是裝彈時繩圈會從上面降下來套你，被套住就動不了，要開槍把繩子打斷。地上的活板門會開。 |
| 教什麼 | 壓力下的對峙。打細小的目標（繩子）。算他的一發。 |
| 場地 | 絞刑台。一座兩層樓高的木頭架子，上下兩層，到處是繩子和活板門。就是當年那一座。 |
| 命 | 4 |

**語氣**：戴著頭套，講話很有禮貌，像在服務客人。全程用「您」。

> **開場**　「您好。請站這裡。對，腳在那個記號上。」
> 　　　　「上次是我服務的，不知道您還記不記得。」
> 　　　　「脖子請放鬆。緊繃的話會比較久。」
>
> **槍戰中**　「請不要動，馬上好。」
> 　　　　　「那條繩子是新的，請不要打它。」
> 　　　　　「不好意思，我只有一發，請讓我裝一下。」
>
> **你輸了**　「這次比上次乾淨。」
> 　　　　　（第三次以後）「您一直回來，表示我一直沒有做好。我很抱歉。」
>
> **最後**　「我做這行三十年，您是唯一一位回來的。」
> 　　　　「我一直想問：那個結，會不會太緊。」
> 　　　　「……謝謝。這樣我知道了。」

### 第六發｜槌子（法官）

| | |
|---|---|
| 當年做了什麼 | 判的。他知道鐘要一條命，知道你是外地人，知道這樣最省事。 |
| 槍 | 一把六發左輪，每一顆子彈上刻著一個名字。前五個名字你已經認識了。 |
| 怪處 | **本庭規定**。他的法槌就是那口鐘的鐘舌。他敲一下、說一條規定，那條規定就是真的：「本庭規定，不得翻滾。」雙方都要守——但規定是他定的。 |
| 對峙花招 | **槌子就是鐘**。他敲三下，只有第三下算。後面的階段他會在敲之前先宣布一條規定：這一輪不得瞄準、這一輪不得憋氣、這一輪後拔的人先開槍。 |
| 槍戰 | 每一條命他定一條規定，禁掉一種你會的事。他開的每一槍會用上前面一個人的本事：棺材、假聲、「站住」、拍子、繩子。第六顆子彈上刻的是你的名字——判決書上那個不是你的名字。 |
| 教什麼 | 期末考。你學過的每一樣，輪流被拿走一樣。 |
| 場地 | 教堂塔頂，鐘的正下方。鐘沒有舌，所以這七年它其實沒有響過——每一次都是他敲的。 |
| 命 | 5 |

**語氣**：累，講話像在唸紀錄。不辯解。每句話都像已經講過很多次。

> **開場**　「請被告站好。」
> 　　　　「喔。這裡現在沒有被告了。習慣。」
> 　　　　「你想問為什麼是你。因為你剛好經過。就這樣，沒有別的。」
>
> **槍戰中**　「本庭規定——」
> 　　　　　「異議駁回。」
> 　　　　　「這一顆是做棺材的。他一直想知道你的尺寸對不對。」
>
> **你輸了**　「退庭。」
> 　　　　　（第三次以後）「你可以一直上訴。我一直在這裡。」
>
> **最後**　「槌子給你。」
> 　　　　「鐘要有人敲。不敲，他們會開始死。小孩、老人，七年份的。」
> 　　　　「敲，就是下一個路過的人。」
> 　　　　「我判了七年，判不出來。換你。」

---

### 結局

你站在鐘下面，手上是法槌。沒有選項框，看你做什麼：

- **敲鐘**：鎮上的人繼續死不了。你坐進法官的位置。下一個路過的人進了鎮。
- **把槌子丟下塔**：鐘再也不會響。欠了七年的，鎮上一夜之間還清。你也是其中一個。
- **拿著槌子走出鎮**：鐘舌不在鎮上了。你走到鎮界的木樁前面。走不走得過去，畫面停在你抬腳的時候。

之後開放二周目（Boss 多一個花招、拔槍再快一點）。

### 文本規範（沿用並調整）

1. 每個人只用自己那一行的話。棺材匠講尺寸和木頭，警長講規矩，劊子手講服務。
2. 沒有人解釋自己的怪處。
3. 沒有人說「命運」「正義」「復仇」。沒有金句、沒有排比。
4. 沒有人承認自己是壞人，也沒有人喊冤。他們講的是當天的一件小事。
5. 輸了的台詞會記次數。
6. 主角全程不超過十句話。牧師那一場，他有機會說，他不說。

## 7. 演出

- **對峙本身就是演出**：風聲、招牌吱呀響、鎮民安靜下來。你的手在畫面下緣，對手在街的另一頭很小。鐘繩在塔上。
- **入場**：每個人做一件只有他會做的事——棺材匠拿皮尺隔空量你；白話從你背後講話，人卻在你前面；警長幫你把槍套的扣子扣上；牧師請會眾起立；劊子手幫你套繩圈；法官讓你自己走上塔。
- **命中**：第一人稱。挨槍時畫面被打歪、濺血、耳鳴。打中對手時他整個人被打退半步，帽子飛掉、血噴在後面的牆上。
- **搶拍成功**：短暫慢動作，他的槍被打偏，一聲金屬響。
- **最後一槍**：子彈視角慢鏡頭，從你的槍口到他身上。
- **輸了**：畫面一黑。棺材蓋從裡面被推開，你坐起來，在棺材鋪裡。三姑的聲音從外面傳進來。
- **每掉一條命**：鐘響，雙方收槍走回原位。Boss 邊走邊講一句話。

## 8. 難度

目標不變：每個 Boss 3–5 次過。

| 發 | 預期嘗試 | 新的壓力 | 這時你該會的 |
|---|---|---|---|
| 1 棺材匠 | 2–3 | 無。把流程走一遍 | 對峙、裝彈、搶拍 |
| 2 白話 | 3–4 | 假訊號、假目標 | 用看的，不用聽的 |
| 3 警長 | 3–5 | 命令、沒有掩體 | 憋氣的取捨 |
| 4 牧師 | 3–5 | 距離、節拍、回血 | 聽拍子、跳彈 |
| 5 劊子手 | 4–6 | 輸對峙直接少一條命 | 壓力下拔槍 |
| 6 法官 | 5–7 | 規定會禁掉你的招 | 全部 |

讓人輸得明白的做法沿用舊版：每一槍前都有擊錘聲和反光、Boss 的招數少而固定、重試很快（棺材蓋一推就回到街上）。輸在同一招兩次，三姑會多講一句風涼話，裡面就是提示。

## 11. 製作順序

1. 對峙原型：一條街、一個稻草人對手、鐘、拔槍與準星。先確認這一段好玩。
2. 槍戰：裝彈、翻滾、掩體、搶拍、膽、憋氣。

6. 平衡與打磨。

## 12. 想問你的

1. **名字**：《六響》可以嗎？（六個人、六發子彈、鐘。）
2. **Boss 掉怪槍？** 你說不要可換能力，所以我沒有讓 Boss 掉帶超自然效果的槍，武器只有 7 把普通的槍。如果覺得太少，可以讓每個 Boss 掉他的槍（例如白話的掌心雷開槍聲會從別處傳出）。要不要？
3. **成長太少嗎？** 現在是每場固定拿一樣小東西。改槍拿掉之後，要不要補別的成長（例如用賞金買彈帶、皮套這類裝備）？
4. **放過他？** 舊版我加了「可以不殺」。這一版每個人最後都是你開最後一槍，沒有放過的選項。要不要留？
5. **劊子手那場**把你吊著對峙，輸了直接少一條命，是全遊戲最硬的一段。可以接受嗎？
6. **中文語感**：人名用綽號（老量、白話、老好人、晚禱、活結、槌子），鎮名「啞鐘鎮」。要不要改成比較像翻譯西部片的名字？
